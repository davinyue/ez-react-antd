# 修复 RemoteTable 横向滚动条

## 背景

当前前端项目中部分页面使用 ez-react-antd 的 RemoteTable。RemoteTable 在数据和列宽不需要横向滚动时仍出现横向滚动条，影响页面展示。

## 目标

RemoteTable 仅在表格列实际需要横向溢出时启用横向滚动。

## 范围

本次修改 RemoteTable 桌面端表格的横向滚动判断逻辑，并补充对应测试。

## 非目标

不调整移动端卡片布局，不重构 RemoteTable 数据加载、分页、展开行等逻辑。

## 关键设计

根据列配置中的显式宽度计算表格最小内容宽度。只有当可计算列宽超过容器宽度时才向 Antd Table 传入 `scroll.x`；无法计算列总宽时保持默认行为，避免因为无条件开启横向滚动导致多余滚动条。

## 验收标准

- 列宽总和小于等于容器宽度时，RemoteTable 不启用横向滚动。
- 列宽总和大于容器宽度时，RemoteTable 继续启用横向滚动。
- 现有类型检查和相关测试通过。

## 当前进度

已定位到 RemoteTable 桌面端无条件传入 `scroll.x` 是多余横向滚动条的主要触发点。已改为按列宽与容器宽度判断是否启用横向滚动，并补充单元测试覆盖无需滚动和需要滚动两种场景。

已通过 Chrome DevTools Protocol 查看 `ez-portal-platform-fe` 页面 `http://172.19.168.30:82/?menuid=67d13fd01326e1293ab36343`。页面 iframe `/admin/menu/list` 中主表格实际 `scrollWidth` 与 `clientWidth` 相等，没有真实横向溢出，但底部仍显示横向滚动条，符合本次修复的问题现象。

## 风险与阻塞

当前暂无剩余阻塞。前端使用方需要更新到包含本次修复的 ez-react-antd 构建版本后才能持续获得该修复。
